# 可靠采集、确认记忆与本机维护

本轮增量迁移为 `f13a8_optimization`，前序为 `e02f7_evidence_policy`。现有原文、人工编辑、会话、偏好及采集选择保留。原生更新也不自动修改系统授权。

## 采集诊断

首页的“采集状态”展示当前进程的新鲜心跳、实际截图、OCR 请求与成功次数、忙碌跳过，以及收到上传和最新入库记录的时间。截图成功、OCR 成功、上传确认和记录入库是不同阶段；重复画面被过滤时，不会伪造新的入库进展。

“查看诊断与修复”提供辅助功能/屏幕录制设置、定位当前应用、重开本项目采集端的固定操作。诊断事件只保存原因和无正文计数，保留30天。安全输入、排除应用/窗口、没有窗口、空文字、暂停、锁屏和温度过高单独展示；长时间没有进展或上传持续失败才提示链路异常。睡眠或无观测时间不算连续故障。

文字队列满后暂停新采样，继续上传未确认文字；获得确认后恢复，保持用户原先的开始/暂停选择。原生应用采用暂存构建、签名验证、替换的顺序；旧应用保留在 `.run/previous-WorkMemory.app`，签名、二进制摘要及采集选择记录到忽略的 `.run/native-update.json`。可选稳定签名身份配置见管理文档。

## 从摘录确认长期记忆

来源页每条摘录旁提供“编辑并长期留存”。用户编辑正文、回顾日期与项目，先预览，再明确确认。请求标识和来源版本防重复与旧页面覆盖。这个流程不创建聊天会话，也不把屏幕上出现的文字直接当作用户成果。

确认后的记忆独立保存，原文自然到期不删除它；主动删除原文时，关联记忆一起删除，删除预览列出清单并在确认时重核。主动纠正原文后，关联记忆变为“待重新核对”，退出检索及模型材料，用户重新确认后才恢复。对记忆的删改同步清理依赖它的答案、报告、提案、Pi 内容与气泡。

“偏好与状态 → 确认记忆与到期核对”可按已确认、待重新核对以及7天内到期的摘录查看；长期记忆支持分页、编辑、忘记和查看来源。独立记忆的日期默认按应用时区计算，用户可以明确调整；项目与日期用于报告材料和检索范围。

## 日报和周报

打开日报/周报只读取当前资料，不调用生成模型。界面按项目列出已确认材料，未确认屏幕摘录折叠展示；摘录不会进入成果草稿。由来源确认的独立记忆默认选中，同期聊天确认记忆可供选择但不默认选中。

点击“一键生成确认材料草稿”后，固定材料及其版本进入持久任务；生成前后再次验证来源。草稿单独保存，可重新生成，不覆盖人工稿。旧请求不能覆盖新草稿；采用草稿开始编辑时绑定准确的草稿版本及来源依赖。模型仍可能概括有误，应核对后保存。

人工稿依赖的来源失效时隐藏旧内容，保留“核对保留的人工编辑”入口。本人明确重新确认保存后，按新的人工表述保留，不会被旧失效依赖反复隐藏。此操作不恢复原文或被删除的记忆。

## 桌宠反馈与完成鼓励

主动气泡菜单和网页“陪伴记录”可选择“喜欢这类话”“这个话题少说”“恢复默认偏好”。显式反馈调整对应话题的选择权重，不从关闭气泡、停留时间或其他动作推断喜好。未展示、失效、超过24小时的记录不能反馈；完成鼓励不改变普通话题偏好。

“今天先安静”持续到应用时区次日零点；原有“安静一小时”保留，正式事项提醒不受影响。

用户主动完成事项/本次提醒后，可由现有 Pi 生成一句普通鼓励；默认开启，可在主动陪伴设置中单独关闭。生成不接收事项正文，也不推断成果、时长或质量。最多每天3句，至少间隔30分钟，并计入整体主动陪伴展示上限。隐藏、全屏、锁屏、聊天、正式提醒、模型忙、节能或安静时段均会跳过；机会只保留60秒，错过不补弹。重复点击完成不会重复生成事件。气泡保持无声、不抢焦点。

## 备份与后端维护

“偏好与状态 → 备份与维护”显示数据库/备份空间、备份列表、最近任务、独立恢复验证及记忆后端冷却状态。可手动备份、验证归档、打开备份目录、切换每天自动备份和主动重试后端。

默认每天应用时区03:00创建本机 PostgreSQL 备份；服务停机后只补最近一次，不唤醒电脑，不连续补齐多天。失败每小时重试，旧的未开始自动任务合并到最近一次。关闭自动备份不领取排队中的自动任务，已开始的备份可以完成，手动任务仍可执行。

保留最近7个备份日与最近4个备份周的最新代表归档，两者合并去重。仅带本维护器归属标记的自动文件参与清理；手动、升级和未登记备份保留。后台独立子进程执行 `pg_dump`，使用文件锁与任务归属标记恢复中断任务，绝不接管未登记文件。归档及清单仅本人可读。

验证先核验 SHA-256，再创建独立临时库，执行 `pg_restore --exit-on-error`，检查迁移版本、全部公共表的计数与约束，最后删除临时库。只返回结构/计数，不返回业务正文。本轮不提供覆盖当前业务库的网页按钮。备份包含创建时的历史内容，删除业务记录不会改写旧备份；迁移机器还需保存配置、凭据、皮肤和项目文件。

可选记忆后端连接失败后，按整个后端冷却60秒、5分钟、15分钟、最多1小时。冷却期间不逐条消耗清理任务的重试次数，选中后端的任务优先继续；网页“立即重试”清除冷却并重新安排待处理/失败任务。后端离线时来源校验继续生效，删除内容不会因后端恢复而重新被采信。
