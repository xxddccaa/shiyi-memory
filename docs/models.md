# 在网页中配置整理与问答模型

打开拾忆网页，进入 **偏好与状态 → 整理与问答模型**。可以选择项目管理的本地 Ollama，或使用 OpenAI 兼容协议的局域网／云端服务。没有网页配置时，默认沿用 `app.local.yaml` 中的本地 Ollama 生成模型。

## 填写与保存

| 字段 | 填写方式 |
|---|---|
| 生成服务 | 本地 Ollama，或 OpenAI 兼容接口 |
| 模型名称 | 服务实际提供的完整模型名称；本地可从已安装模型中选择 |
| 接口基础地址 | 兼容接口通常形如 `http://服务器地址:8000/v1`，不要加 `/chat/completions`；本地地址由管理器配置 |
| API Key | 需要认证时填写；无认证的局域网服务留空 |
| 思考模式 | 通用服务使用“服务默认”；接受 Qwen thinking 参数的服务可显式关闭或开启 |
| 结构化输出 | 默认 JSON Schema；服务不支持时可以尝试 JSON 对象兼容模式 |
| 最大输出 Token | 聊天的每次模型请求直接采用此值，不再额外限制为 2,200 token；新建兼容服务默认 32,768，本机默认仍为 4,096，后台整理任务可使用较小输出值 |
| 模型上下文 Token | 填写服务实际支持的输入加输出容量；支持 1M 时填 1,000,000，需为输出和压缩留足空间。本机编程必填；普通聊天可留空，但仅使用标注为估算的临时容量 |
| 请求超时／温度 | 在高级参数中调整；输出较长时可按服务速度提高超时 |

点击 **仅测试连接**，使用固定合成文字验证中文回复、17×23 的结果和结构化 JSON，不会修改当前设置，也不读取工作记录。点击 **验证并保存** 会再次验证，成功后保存并即时应用；测试失败或文件写入失败，原设置继续有效。

页面显示“当前生效”的模型与地址，编辑但未保存的内容有标记。打开多个页面时，旧页面不能覆盖较新的配置；出现版本冲突后点击“重新加载”。保存不需要重启采集端。已发送的模型请求允许完成，排队中的旧配置请求会失效；后台任务按持久队列规则重试，交互问答会提示重新提交。

API Key 保存在本机权限为 `0600` 的 `config/generation.local.json`，与配置原子写入，不提交 Git。网页不回显密钥，也不把模型密钥写入浏览器存储。相同服务地址留空表示保留密钥；更换服务地址或协议时不会沿用旧密钥；勾选“清除已保存的 API Key”可移除它。默认卸载保留这份配置，彻底清除会删除。

## 输出长度与上下文容量

1M 上下文表示模型单次请求的上下文容量，不能替代单次最大输出。聊天之前还受 2,200 token、6,000 字符正文和 20 个引用等独立硬编码影响；这些额外上限已移除，回答继续逐条验证所引用来源。

填写 `context_window` 后，Pi Coding Agent 使用该容量和实际返回的 token 用量决定自动压缩时机，生成任务摘要、保留近期消息后继续。容量为 `C`、输出为 `O` 时预留 `max(O + ceil(0.02C), min(16384, ceil(0.2C)))`，其值必须小于 `C`。1M/65,536 设置对应约 914,464 的触发阈值和 200,000 的近期保留目标。也可以在聊天中点击“立即压缩”。摘要调用同一个模型与生成调度器，属于上下文管理，不会自动保存为个人记忆。

提供方未返回 usage 时显示估算；普通聊天未填容量时，临时采用至少 YAML `agent.context_chars` 或两倍最大输出的估算容量，并明确标注。编程模式要求先填写真实容量。字符不等于 token，估算及服务端声明均不等于实际满窗口性能验收。本机 Ollama 的生成请求采用填写的上下文值，嵌入仍使用原配置。业务工具的单次摘录仍有结构化分页或范围限制，Pi 可继续读取，不再直接丢弃旧聊天轮次。

连接测试使用很短的合成内容，但携带实际配置的最大输出参数，可发现服务拒绝该参数；成功不证明已经实际处理满窗口或生成满输出。界面不再把最大输出限制在 8,192 以内。旧保存配置的显式输出值不会静默覆盖，需保存新的值；本地文件增加可选字段无需数据库迁移。服务仍返回 `length` 时说明服务停止了生成，错误提示应检查单次输出和服务端上限，不要求缩短简单问题。自动更换服务、提高保存值或重放操作均不发生。

## 各模块的使用位置

- **整理与问答**：使用网页选定的生成服务，包含活动摘要、项目／待办提取、证据问答、Pi 编程与上下文压缩，以及 Graphiti 需要的生成请求。
- **嵌入检索**：继续使用项目管理的本机 Ollama 与 `qwen3-embedding:0.6b`，1024 维。网页展示此配置，暂不提供嵌入模型切换，以免已有索引维度或语义空间失效。
- **OCR**：继续使用本机 PaddleOCR tiny，五秒节拍、忙碌跳过和跨片段去重保持原有规则。网页展示检测／识别模型。

保存远程生成配置后，后续整理所需的工作文字、问答上下文，以及编程时读取的文件/命令输出和压缩输入会发送到所填服务。截图只在本机 OCR 处理。连接失败不会自动改用本地或其他云端服务。生成服务的 API Key 不会发送到本地嵌入服务。

一个聊天服务不一定提供嵌入接口。生成模型切换不需要重建当前记忆索引，也不会自动重新整理已有摘要。

## 状态、下载与排查

管理入口“查看状态”会显示所选生成模型、服务地址及检查状态。本机 Ollama 始终用于嵌入；选择远程生成后，安装／修复只要求本地嵌入模型，不再要求下载默认本地生成模型。切回未安装的本地生成模型时先安装模型，再验证并保存。

服务状态使用模型列表接口进行轻量检查，不持续运行生成请求。有些兼容服务不提供 `/models`，因此模型列表检查失败不等于聊天一定失败；以网页的实际连接测试为准。出现 400 可检查思考参数或 JSON 输出模式，401／403 检查密钥与权限，404 检查地址和模型名。

兼容服务的加载／切换时间未提供时，网页显示“未提供”，不把它当作零耗时。推理耗时与排队时间仍记录在最近模型请求中。

开发接口均要求原有的本机访问令牌：

- `GET /api/config/models`：读取不含密钥的配置与版本。
- `POST /api/config/models/test`：只测试传入配置。
- `POST /api/config/models`：验证、保存并应用配置。

网页保存的生成设置优先于 YAML 中的默认生成模型。数据库、端口、嵌入与 OCR 等应用配置仍由本地 YAML 和管理脚本负责。不要把生成服务密钥放进 URL、日志或可提交的配置模板。
